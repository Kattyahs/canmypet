# CanMyPet

Web platform to check food safety risk levels for pets by species, manage
multiple pet profiles, keep search history, and access emergency guidance.
Includes a veterinarian role for verifying food safety entries.

## Tech stack
- Backend: Java + Spring Boot + Spring Security (JWT) + Maven
- Frontend: React + Vite + Tailwind CSS
- Database: PostgreSQL
- Containerization: Docker & Docker Compose

## Getting started
1. Copy `.env.example` to `.env` and fill in real values.
2. Run `docker compose up --build`.
3. Backend: http://localhost:8080
4. Frontend: http://localhost:5173

## API documentation
Postman collection available at `docs/postman/`.
